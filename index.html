Add vehicles from CTDMS

Pick the purchase Excel exported from CTDMS, as it comes. The app shows what it will add; only vehicles not already in Purchase Data are added, in the next empty rows. Nothing can be deleted.

These vehicles show no HSN code in Purchase Data because their suffix code is not in the HSN list (input tab). Enter the HSN once per suffix code: it is added to the list and every vehicle of that suffix, now and later, gets it.
